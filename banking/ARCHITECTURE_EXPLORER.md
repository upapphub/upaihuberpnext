# Architecture Explorer

This module adds a read-only web UI for visualizing repository architecture.

## Route

- Open `/banking/architecture` in ERPNext.
- In the banking app home screen, use the `Architecture` button in the header.

## How graph data is generated

The graph is generated by:

- `banking/build-architecture-index.mjs`

It scans the full repository and emits:

- `banking/public/architecture-index.json`

The JSON contains:

- `nodes`: directory and file nodes with metadata (`domain`, `language`, `size`, `updatedAt`).
- `edges`: structural (`contains`) and dependency (`imports`) relationships.

## Build integration

`banking/package.json` build flow now runs:

1. `yarn build:architecture-index`
2. `vite build --base=/assets/erpnext/banking/`
3. `yarn copy-html-entry`

This keeps the architecture graph artifact fresh for production bundles.

## Manual refresh

If you only want to refresh graph data after refactors:

```bash
cd banking
yarn build:architecture-index
```

## Exclusions and guardrails

The indexer excludes generated/noisy directories (for example `node_modules`, `.git`, cache/build folders) and skips oversized files to keep generation fast and stable.
